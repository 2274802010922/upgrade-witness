# Changelog

## 0.1.0-alpha.1 — 2026-10-16

- Add the `doctor` and `verify` CLI commands for trusted, committed React/Vite npm projects.
- Capture each side twice and compare semantic assertions, intended changes and screenshot evidence.
- Write HTML, Markdown and JSON reports with coverage, immutable revision identities and artifact hashes.
- Add the Upgrade Witness skill, an original synthetic Tailwind migration example and bilingual documentation.
- Include MIT, contribution templates, private vulnerability reporting and Windows/Linux CI configuration.

This is an early alpha. Independent benchmark targets and external pilots remain pending. No public npm package is claimed.
